Help & Documentation

Essential guide to writing code, running simulations, and interpreting results.

Verilog Simulation Guidelines

  • Testbenches: Verilog requires a testbench module (e.g., module tb; ... endmodule) with clock or stimulus signals to produce waveform transitions.
  • Waveform Recording: Use $dumpfile("dump.vcd"); and $dumpvars(0, tb); inside an initial begin ... end block. The platform also automatically injects this if omitted!
  • Termination: Always terminate your testbench execution with #time $finish; to avoid execution timeouts.
  • Standard: Compiled with iverilog -g2012 supporting IEEE Verilog 2001 and 2012 syntax extensions.

MATLAB / GNU Octave Guidelines

  • Compatibility: GNU Octave is a high-level language primarily intended for numerical computations, highly compatible with MATLAB scripts.
  • Plotting: Call plot(x, y), title('...'), xlabel('...'), and grid on. The simulator automatically renders interactive charts and extracts line curves.
  • Waveform Variables: If variables t and y exist in your script, they are automatically parsed into the waveform visualizer.
  • Toolboxes: Octave provides built-in core linear algebra, signal processing, and numerical solvers. Proprietary MATLAB toolboxes (e.g. Simulink) are not included.

Troubleshooting Common Errors

  • Syntax Error / Unterminated String: Check for missing semicolons (;) in Verilog or unclosed quotes.
  • Simulation Timed Out: If your Verilog testbench lacks $finish; or includes an infinite forever loop, the 10s safety timeout terminates the process.
  • Matrix Dimension Mismatch: In Octave, ensure matrix inner dimensions agree for multiplication (*) or use element-wise operators (.*, ./).
  • Security Restriction: Shell command calls (system, unix, dos) are disabled for sandbox safety.

About ECE Code Simulator

Bridging the gap between engineering theory and browser-based hands-on practice.

ECE Code Simulator is an open educational platform engineered to provide instant, zero-configuration access to core Electrical and Computer Engineering simulation tools.

Commercial engineering software suites often require multi-gigabyte downloads, strict licensing, and high-performance workstations. This creates barriers for students and self-learners globally. ECE Code Simulator solves this by executing simulations on secure cloud infrastructure and rendering timing waveforms and mathematical plots directly in standard web browsers on any computer, tablet, or phone.
